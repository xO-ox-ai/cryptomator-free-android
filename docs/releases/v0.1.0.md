## English

**This is an independent, unofficial fork. It is not affiliated with, endorsed by, or supported by Cryptomator, Skymatic GmbH, or the upstream maintainers.**

### Upstream baseline

- Upstream: [cryptomator/android](https://github.com/cryptomator/android), `develop` branch.
- Original version: **2.2.0-SNAPSHOT development build**, not an official stable 2.2.0 release.
- Exact commit: [`4ebaeb9a3a03929eaf2b6aabfbffef5a5b933756`](https://github.com/cryptomator/android/commit/4ebaeb9a3a03929eaf2b6aabfbffef5a5b933756), dated 2026-11-05, 70 commits after upstream tag `2.1.0`.
- Fork modifications: 2026-11-10; APK source commit `4695071ad60ca2a1c19424bf16fe02c7fc48c9bd`.
- [Full upstream provenance and modification notice](https://github.com/xO-ox-ai/cryptomator-free-android/blob/v0.1.0/UPSTREAM.md).

### Features and changes

- Named **Cryptomator Free**, with an original shield-and-F icon.
- Permanent app read/write access without a purchase, subscription, or trial; no official license is generated or forged.
- Purchase onboarding, billing services, official promotions, and official APK self-updates are disabled.
- The welcome screen, settings, and repository README identify the fork as unofficial and name the upstream baseline.
- Help links point to this fork; log sharing does not prefill the upstream support email.
- Upstream encryption and the vault format are unchanged.

### Installation

Download **`Cryptomator-Free-0.1.0-lite.apk`**. Requires Android 8.0 or later.

- Package: `io.github.xooxai.cryptomatorfree.lite`.
- Supported: **local folders, WebDAV, and S3**.
- Not included: Dropbox, Google Drive, OneDrive, SharePoint, pCloud, Box, and other integrations requiring separate API configuration.
- Signed with an independent release key and installable alongside the official app. It cannot replace the earlier Cryptomator Community debug test build.

For offline use, create an accessible folder on your phone, such as `Documents/Cryptomator-Free`, and select it through **Local storage**. Sync the entire encrypted vault, not the decrypted file entry. Nextcloud Android's automatic upload feature is not equivalent to complete two-way folder synchronization and needs separate verification.

### Verification and limitations

The release build completed successfully. Relevant tests: **25 passed; 2 skipped because they do not apply to free builds**. APK signature and alignment checks passed, and the package is not debuggable. The GitHub build also passed for the APK source commit.

**Android device testing, offline read/write testing on a device, and Nextcloud synchronization testing remain outstanding. The fork has not received an independent security audit, so this is a preview release.**

### 安装

下载 **`Cryptomator-Free-0.1.0-lite.apk`**。需要 Android 8.0 或更高版本。

- 包名：`io.github.xooxai.cryptomatorfree.lite`。
- 支持：**本地目录、WebDAV、S3**。
- 不包含：Dropbox、Google Drive、OneDrive、SharePoint、pCloud、Box 等需要独立 API 配置的集成。
- 使用独立发行签名，可与官方版并存。它不能覆盖早先名为 Cryptomator Community 的调试测试包。

离线使用时，请在手机上创建一个普通可访问目录，例如 `Documents/Cryptomator-Free`，在应用中通过“本地存储”选择它。同步时应同步整个加密保险库，不能同步解锁后的明文入口。Nextcloud 安卓端的自动上传不等同于完整双向文件夹同步，需另行验证。

### 验证范围与限制

发布版已编译，相关测试 **25 项通过、2 项因免费构建不适用而跳过**。APK 签名及对齐验证通过，安装包未启用调试标志。APK 对应源码的 GitHub 自动构建也已通过。

**尚未进行安卓真机离线读写或 Nextcloud 同步测试，也未接受独立安全审计，因此标为预览版。**
